# **Online Food Delivery Project**

## Project Overview

The **Online Food Delivery System** is a Full-stack web Application

- React
- Spring Boot
- Spring Security
- role base access (ROLE_CUSTOMER,ROLE_RESTAURANT_OWNER)
- Spring start mail
- Jeson web token
- Mysql
- Tailwind css
- Mui (css component library)
- Redux (State managment library)
- Axios
